# 🚀 Spider Pet - Quick Start (5 minutes)

## Download & Install

1. **Get the APK**
   - Go to: https://github.com/YOUR_USERNAME/spider-pet/releases
   - Download `app-release.apk`
   - Download to your phone

2. **Install on Android**
   - Open File Manager → Downloads
   - Tap `app-release.apk`
   - If it says "Unknown source", go to Settings → Security → Unknown Sources → ON
   - Tap "Install"
   - Done! ✅

## First Time Setup

1. **Open Spider Pet**
2. Tap **⚙️ Settings**
3. Tap **Add Free Groq API Key**
4. Get free key at https://console.groq.com
5. Paste key into app
6. Tap **Save**

## Features

- **🕷️ Pet walks around** - Random movement
- **💬 Talk** - Direct chat with Spider
- **🤗 Pet** - Physical affection
- **🎮 Play** - Interaction games
- **👀 Show Me** - Describe what's on screen
- **📊 Relationship** - Builds over time (0-100%)
- **🎬 YouTube** - Watch together

## Tips

- Interact multiple times to build relationship
- "Show Me" uses more API but gets better responses
- Mood changes based on relationship level
- Spider remembers your interactions
- Free API = unlimited usage 🎉
