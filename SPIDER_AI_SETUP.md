# 🕷️ Spider AI Setup Guide

Spider is now **intelligent**! She can understand your conversations using Claude's AI and even see what you're doing on your phone.

---

## 🔑 Getting Your Claude API Key

### Step 1: Go to Claude Console
Visit: **https://console.anthropic.com**

### Step 2: Create/Sign In to Account
- Sign up (free) or log in
- Verify your email

### Step 3: Create API Key
1. Go to **API Keys** section
2. Click **Create Key**
3. Name it: `spider-pet`
4. **Copy the key** (starts with `sk-ant-`)
5. **Save it somewhere safe** (you'll need it)

### Step 4: Add Free Credits (Optional)
- Anthropic gives free credits for new accounts
- ~$5 free usage to test
- Pay-as-you-go after that (very cheap)

---

## 📱 Adding API Key to Spider App

### In App:
1. Open Spider Pet app
2. Tap **⚙️** (settings, top right)
3. Tap **❌ Add Claude API Key**
4. Paste your `sk-ant-...` key
5. Tap **Save Key**
6. Done! ✅

**Now Spider can understand you!**

## ⚙️ Troubleshooting

### "Invalid API Key"
- Double-check you copied it correctly
- Make sure it starts with `sk-ant-`
- Regenerate key at console.anthropic.com if needed

### "API Error: 401"
- Invalid or expired key
- Regenerate at console

### "Connection failed"
- Check internet connection
- Try again in a moment
- Anthropic servers are reliable

### "Spider not responding"
- Make sure API key is saved
- Check your internet
- Claude API might be busy (rare)
