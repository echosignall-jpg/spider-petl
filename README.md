# 🕷️ Spider Pet - Your AI Companion

Free, ad-free, AI-powered pet that understands your screen and chats with you.

## Features

✨ **AI-Powered** - Uses free Groq API (no payments ever)
🕷️ **Animated Pet** - Spider walks around your screen
💬 **Smart Chat** - Responds based on your relationship level
👀 **Screen Awareness** - Tell Spider what you're doing
📊 **Relationship System** - Builds over time (0-100%)
🎮 **Interactive** - Talk, Pet, Play
🎬 **YouTube Together** - Watch videos with Spider
💾 **Persistent** - Saves your data locally
📱 **Mobile Native** - React Native app

## Download

Latest release: https://github.com/YOUR_USERNAME/spider-pet/releases

## Quick Start

1. Download APK
2. Install on Android (Settings → Security → Unknown Sources → ON)
3. Get free Groq API key at https://console.groq.com
4. Open app, add API key, start chatting!

## Cost

**$0** forever. Free Groq API covers thousands of messages monthly.

## Requirements

- Android 5.1+ (API 21+)
- Internet connection
- Free Groq API key

## Files

- `app.js` - Main React Native app
- `package.json` - Dependencies
- `.github/workflows/build-apk.yml` - Auto APK builder
- `GROQ_API_SETUP.md` - API setup guide
- `QUICKSTART.md` - Quick start guide

## Building Locally

```bash
npm install
npm run android          # Requires Android SDK + Java
# OR
npm run build-apk       # Requires gradle
```

## Building on GitHub (Recommended)

1. Push to GitHub
2. GitHub Actions auto-builds APK
3. Download from Releases
