## 📋 What You Need to Do

### To Get APK (25 minutes)

1. **Create GitHub Account**
   - [ ] Go to https://github.com
   - [ ] Sign up (free)
   - [ ] Verify email

2. **Create Repository**
   - [ ] Click + → New repository
   - [ ] Name: spider-pet
   - [ ] Create

3. **Upload Files**
   - [ ] Go to /home/claude/PetAI/
   - [ ] Upload all files to GitHub (or use git push)
   - [ ] Commit changes

4. **Wait for Build**
   - [ ] Go to Actions tab
   - [ ] Wait 10-15 minutes for build
   - [ ] See green checkmark

5. **Download APK**
   - [ ] Click completed workflow
   - [ ] Find Artifacts section
   - [ ] Download app-release.apk

6. **Install on Phone**
   - [ ] Transfer APK to phone
   - [ ] Enable Unknown Sources (Settings → Security)
   - [ ] Tap APK → Install

7. **Add API Key**
   - [ ] Open Spider Pet app
   - [ ] Tap ⚙️ Settings
   - [ ] Get free key from https://console.groq.com
   - [ ] Paste key in app

8. **Done!** 🎉
   - [ ] Start chatting with Spider
