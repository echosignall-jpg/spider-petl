# 🎉 Spider Pet - What's New

## Version 1.0.0 - Initial Release

### Features ✨
- 🕷️ **Animated Spider Pet** - Walks around your screen
- 💬 **AI Chat** - Powered by free Groq API
- 🤗 **Interactions** - Talk, Pet, Play buttons
- 👀 **Screen Awareness** - Tell Spider what you're doing
- 📊 **Relationship System** - 0-100% builds over time
- 💾 **Persistent Data** - Saves locally
- 🎬 **YouTube Integration** - Watch together
- ⚙️ **Settings** - Manage API key
- 🎨 **Clean UI** - Simple and cute design

### Integrations 🔗
- **Groq API** - Free, unlimited, no payments
- **AsyncStorage** - Local data persistence
- **React Native** - Cross-platform

### What's Free 🎉
- ✅ App download
- ✅ AI interactions (powered by Groq)
- ✅ All features
- ✅ No ads
- ✅ No payments (ever)
- ✅ Open source

### System Requirements 📱
- Android 5.1+ (API 21+)
- 50-80MB storage
- Internet connection
- Free Groq API key (takes 2 minutes)

### Known Limitations 🤔
- Android only (iOS coming soon)
- Screen overlay only works in-app (not system-wide)
- Requires internet for AI responses
- API key stored locally (keep it safe!)
