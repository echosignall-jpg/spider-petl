## 🎯 FASTEST METHOD (GitHub Actions - 10 minutes)

### Step 1: Create Free GitHub Account (2 min)
1. Go to **https://github.com**
2. Click **Sign up**
3. Enter email, password, username
4. Click **Create account**
5. Verify your email

### Step 2: Create New Repository (1 min)
1. Log in to GitHub
2. Click **+** icon (top right)
3. Click **New repository**
4. Name: **spider-pet**
5. Description: **Free AI Pet**
6. Click **Create repository**

### Step 3: Upload All Files (2 min)
Your app files are at: `/home/claude/PetAI/`

**Option A: Upload via GitHub Website (Easiest)**
1. In your new repo, click **Add file** → **Upload files**
2. Open File Manager on Termux:
   ```bash
   cd /home/claude/PetAI
   ls -la
   ```
3. Drag these files into GitHub:
   - ✅ app.js
   - ✅ index.js
   - ✅ app.json
   - ✅ package.json
   - ✅ .gitignore
   - ✅ README.md (all .md files)
   - ✅ android/ (entire folder)
   - ✅ .github/ (entire folder)

4. Click **Commit changes**

**Option B: Upload via Git Commands (Termux)**
```bash
cd /home/claude/PetAI
git init
git add .
git commit -m "Initial commit - Spider Pet v1.0.0"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/spider-pet.git
git push -u origin main
```

### Step 4: GitHub Actions Builds APK (10-15 min)
1. Go to your repo
2. Click **Actions** tab
3. Wait for **Build APK** workflow to finish (green checkmark)
4. Click on the completed workflow
5. Scroll to **Artifacts** section
6. Download `app-release-apk.zip`

### Step 5: Install on Your Phone (3 min)
1. Transfer APK to your phone (email, USB, or cloud)
2. Open **File Manager** on phone
3. Go to **Downloads**
4. Tap the APK file
5. If prompted "Unknown source":
   - Tap **Settings** → **Security** → **Unknown Sources** → **Toggle ON**
   - Go back and tap APK again
6. Tap **Install**
7. Wait 30 seconds
8. **Done!** 🎉

### Step 6: Add API Key (2 min)
1. **Open Spider Pet** app
2. Tap **⚙️** (settings) in top right
3. Tap **Add Free Groq API Key**
4. Go to **https://console.groq.com**
5. Sign up (free)
6. Go to **API Keys** section
7. Create new key
8. Copy key (starts with `gsk_`)
9. Paste into app
10. Tap **Save**

### Step 7: Start Chatting! 🕷️
- Tap **Talk** - Chat with Spider
- Tap **Pet** - Show affection
- Tap **Play** - Interact
- Tap **Show Me** - Describe your screen
- Watch your **Relationship** build!

## 🆘 Common Issues

**"GitHub Actions failed?"**
→ Make sure you uploaded `.github/workflows/build-apk.yml` file

**"Can't find APK?"**
→ Wait 15 minutes after push, then refresh Actions tab

**"Unknown source error?"**
→ Settings → Security → Unknown Sources → Turn ON

**"API key invalid?"**
→ Make sure you copied the ENTIRE key (starts with `gsk_`)

**"App won't open?"**
→ Check if Android version is 5.1+ (Settings → About Phone)

**"Spider not responding?"**
→ Check internet connection, wait a few seconds
