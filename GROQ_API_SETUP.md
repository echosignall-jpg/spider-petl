# 🕷️ Spider Pet - Free Groq API Setup

## What is Groq?
**Groq = FREE AI API, 100% forever, no payments ever**
- Unlimited free tier (generous limits)
- Super fast responses
- Perfect for pet AI interactions

---

## Step 1: Get Your Free API Key (2 minutes)

1. Go to **https://console.groq.com**
2. Click **"Sign Up"** (free account)
3. Fill email, password, accept terms
4. Verify email
5. Go to **"API Keys"** section
6. Click **"Create New API Key"**
7. Name it: `spider-pet`
8. **Copy** the key (starts with `gsk_`)
9. Keep it safe! 🔒

---

## Step 2: Add API Key to Spider App

1. **Open Spider Pet** on your phone
2. Tap **⚙️ (Settings)** in top right
3. Tap **❌ Add Free Groq API Key**
4. Paste your `gsk_...` key
5. Tap **Save Key**
6. Done! ✅

---

## Step 3: Start Chatting!

- **Talk** - Spider responds to you
- **Pet** - Show affection
- **Play** - Interactive games
- **Show Me** - Tell Spider what's on your screen
- **Chat Box** - Direct conversation

Spider will understand context and respond based on your relationship level!

## Troubleshooting

**"Spider isn't responding?"**
- Check API key is correct
- Make sure you're online
- Wait a few seconds (Groq is just slow sometimes)

**"API key says invalid?"**
- Make sure you copied the ENTIRE key
- No extra spaces
- Key should start with `gsk_`

**"Want to switch keys?"**
- Tap ⚙️ → Edit key → Update
